# 用户持续偏好



以下为本用户明确给出的默认偏好，后续具体照片的新指令优先。偏好不扩大人物重绘权限。



## 背景元素

用户原话：“以后背景图片中我不提不要出现月亮这种容易穿帮的东西”。

未明确要求时，不添加可见月亮、太阳圆盘、行星等容易暴露光向、尺度或合成关系的醒目天体，也不自行加入同类抢眼装饰。夜景不等于需要月亮；用自然环境明暗表达夜间。生成背景的提示明确写 no visible moon / sun disk / planets；采用素材前实际检查，模型自行加入时修正或换素材，不把多余元素带入成片。



## 抠图边缘

用户原话：“抠出来的图要对边缘进行羽化来提升与背景的融合度”。

抠图后必须检查并做适度的局部 alpha/蒙版羽化及过渡，再合成背景。仅在原生像素网格的窄边缘带处理透明度，不模糊整个人物 RGB，不改变主体坐标或尺寸。已有自然软边只调整不足之处，避免反复羽化造成收缩、白边、双边或失去发丝。

- 发丝：保留细丝和原有半透明关系，避免统一高斯模糊切掉散发。

- 丝绸、薄纱：保留透光、褶皱和边缘纹理，不能把不透明衣料误处理成透明。

- 硬质配饰与道具：保持清楚形状，仅做细微抗锯齿和背景侧过渡，不圆化轮廓。

- 面部和主体内部细节继续冻结；边缘修改范围单独登记。不得把羽化当作重绘面部、变形或取消人物保护的许可。

羽化半径根据原图尺寸、景深、材质和边缘问题决定，不机械套用统一宽度；以100%局部视图检查发丝、肩袖和道具边缘，消除硬切与色边后再输出。现有后端可合成灰阶蒙版，但没有新增自动材质分区羽化器，蒙版制作与视觉验收仍需实际完成。



## 展示结果

用户原话：“以后不要发我素材图，我只要成图”。

面向用户只展示最终合成成片及其下载链接。独立背景、抠图、特效素材和中间预览仅供内部处理，不主动作为交付展示；用户要求查看时例外。工具如会自动显示素材，应如实区分工具自动预览与最终成片，不把素材称为成图。


## 发光元素与清晰度
用户原话：“该skil如果生成会发光的东西，要有发光感，但是又不能让光线的晕影影响整个画面的清晰度”。
默认保留清楚亮核与贴近光源、向外衰减的局部辉光；不加覆盖全画面的泛光、雾幕或柔焦。辉光独立可调且限定在原尺寸局部蒙版内，不模糊底图或人物，不吞没发丝、服装、配饰和环境纹理。整体及100%局部对比后同时确认发光感与清晰度；失败先修 Glow 范围和扩散，不压暗全部本体或全图锐化补救。具体执行见 [发光感与局部清晰度](effects.md#发光感与局部清晰度)。
