# 自动验收和不能保证的事项

## 可确定验证
- 原图/素材文件 SHA-256 与项目绑定一致；输入模式、方向、色彩元数据受限。
- 输出宽高、模式与输入一致；RGBA alpha 数组相等。
- 人工保护蒙版内全部 RGB/alpha 像素严格相等；因此覆盖充分时人物位置、比例、轮廓和细节被保留。
- 脚本实现不包含 resize/crop/warp/rotate；只允许逐像素调色和同网格合成。
- 每步有效修改范围外像素相等；整体及高风险审批均绑定计划；导出再次检查并核对人工复核哈希。

这些结论只适用于本后端和受限输入，不能证明外部素材制作时没有缩放，也不能证明蒙版漏标或工程被恶意改写。

## 筛查与人工复核
验收统计非保护区输入/输出水平及垂直亮度差分的平均绝对值，输出/输入边缘能量 < 0.85 则失败。原图能量为 0 时输出不引入下降，报告 ratio=null。该筛查可能误拒绝刻意降低背景对比度，也可能放过加噪声、锐化、油画化或色彩细节丢失。不会通过降低阈值绕过失败；修改方案或说明不能完成。

感知清晰度、身份相似、自然材质、照明物理合理性及特效涂抹感没有自动强保证。助手须实际查看整体和原尺寸局部，检查脸/头发/衣服/道具及编辑区，记录具体视觉判断。自动 PASS 只是必要条件；视觉失败不能导出。用户已有直接导出授权时不新增用户确认；助手不能虚构用户已复核。

独立 acceptance.py 不能证明处理历史、审批和分支，只做当前像素对照；retouch.py export 才执行完整项目门禁。脚本不抗恶意用户编辑项目文件。

## 已知限制
基础 retouch.py 仍仅接受无 ICC 的 8-bit sRGB 假设 RGB/RGBA 静态图；JPEG 解码后输出 PNG。不支持 RAW、16-bit、CMYK、HDR、PSD、完整色彩管理和打印流程。不支持自由液化、移位、变形、重构人物、修补生成或图像生成接口。图层堆栈以项目 JSON 和素材保存，不导出 PSD。独立 cutout.py 可保留 sRGB IEC61966-2.1 ICC，输出自动或人工抠图候选素材；自动蒙版内部缩放，不保证边缘完整，不作为原照片成片。

默认严格人物像素锁会限制人物调色与精修。必要时可按 [备用融合](fallback-fusion.md) 的明确授权只修改声明的窄边缘与局部光影，核心保护区和面部仍逐像素固定。该模式不能声称整个人物逐像素不变，也不能保证配饰轮廓可由像素分数自动认证。没有自动纹理保真或重绘后端，不能用占位接口冒充。
