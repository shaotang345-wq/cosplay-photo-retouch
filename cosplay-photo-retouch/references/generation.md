# 参考驱动的局部素材生成与装配

原片修图只允许局部素材。独立概念图可以生成，但须标为新图，不能充当原片成片。

动漫/插画的写实转换仅限 [背景和独立素材](material-realism.md)。不得转换人物、把二次元人物变真人或生成全场景后替换原图；最终合成保留原人物像素。

## 选择路线
- 调色/同尺寸合成用 retouch.py；候选蒙版用 cutout.py。
- 已有透明局部素材用 assemble_asset.py 原尺寸装配。
- 复杂纹理：当前宿主确实有 image_gen 时调用，遵循本机 imagegen 技能及工具参数。本包没有生成 API 客户端，不能保证生成尺寸或纹理质量。
- 工具不可用时复用资产或说明限制，不静默安装厂商 SDK 或改走付费 API。用户指定其他后端时另行核实。

## 一份素材配方贯穿制作
记录用途、参考角色、批准范围、原生目标尺寸、位置、提示词和选用文件哈希。参考分别标明原片/风格/轨迹/材质，用最少足够的参考；不同人物不能混成同一主体。粗图只定义布局，正式生成只针对需要的局部资产，不重新生成脸或用文字重建人物。只重做发生变化的图层，一次修正一个明确问题。

示例提示：
```text
用途：Cosplay 摄影的独立透明局部素材，不输出人物或原照片。
参考：图1仅供能量结构；图2仅供金色材质；粗图仅供布局。
请求：一个窄金色能量弧，细而断续的亮芯，稀疏火星、小范围辉光。
约束：透明背景，不出现人物、衣物、文字、水印或大片发光雾。
目标原生尺寸：1024×1024；返回后检查实际尺寸和 alpha。
```
示例尺寸不代表工具支持任意尺寸。透明请求使用工具实际支持的透明参数；检查真实 alpha，不能把棋盘格图当透明素材。默认尺寸不符不能插值补足；仅独立背景获得明确放大例外时按 scene-integration.md 执行；在原批准范围内重新安排原生素材或停止。小素材不能放大成大特效。

## 原生装配
仅依赖现有 Pillow/NumPy。源图用 cutout.py 输入规则，仅读取画布，不写入原件。素材为无 ICC/gamma/chromaticity、方向为 1 的静态 RGBA PNG，不静默转换色彩。
```powershell
python 'C:\path\to\cosplay-photo-retouch\scripts\assemble_asset.py' --source 'D:\photos\source.jpg' --asset 'D:\assets\arc.png' --protect 'D:\photos\protect.png' --x 3500 --y 500 --output-dir 'D:\photos\arc-layer-v1'
```
输出 layer.png 和哈希报告。整数坐标原样复制 RGBA，不缩放/旋转/裁边；越界、可见 alpha 与保护区相交、空保护蒙版、全透明/全不透明素材或已有输出目录均拒绝。透明像素不参与合成。需要遮挡时先制作并核对原网格素材蒙版，不能移动人物或靠模糊掩饰。

装配只输出素材，仍需进入 retouch.py 已批准计划并通过自动/人工验收。报告不证明 AI 制作历史或审美质量。保留使用中的素材、配方及回退项目；测试用临时目录，不保存第三方仓库、完整 SDK 或重复预览。不能删除版本引用中的资产。本包没有持久化 AI 请求缓存，已有资产和抠图缓存可复用。
