# 快速路径：粗预览 → 原尺寸素材 → 一次合成

优先严格保留主体。若明确的边缘/光影问题阻碍融合，可按 [已授权备用融合](fallback-fusion.md) 执行限定修补；复用持续授权，不重复问相同范围，仍报告核心保护区和可变窄带。

## 只确认缺失的授权
目标和范围明确且已有授权时，用文字说明最小计划后直接制作。新背景或强特效缺少授权时一次询问具体范围；已有授权不重复问。用户只要成片时，粗图、素材与 ROI 留作内部检查，只有用户明确要求才展示。

设计粗图仅在确实需要探索新布局时制作，不是每次修图的必经步骤。已有参考或图层足够时复用，不能为了方案预览无意义消耗生成预算。完整内部验收后输出推荐成片；已有直接导出授权不增加确认点。

## 粗图的正确用途
粗图可以低分辨率，用来描述布局与观感；它不是处理过的原图，也不用于替换原图任何人物像素。坐标先转成原图像素位置或归一化布局，记录为素材配方：来源、用途、原生尺寸、位置、核心颜色、辉光范围、遮挡/保护要求。

不能把低分辨率粗图放大到原图尺寸充当特效成片，也不能把其中的模糊符纹放大冒充新细节。粗图作为风格与布局参考，正式素材在最终需要的原生像素尺寸制作。

## 从设计到正式素材的三条路
- **参考已有原尺寸特效图**：只提取明确区域的符纹等结构，排除背景亮度、人物变化及大面积雾光。效果轨迹可从布局配方在最终像素网格直接绘制。不能无范围地按整图差分提取，避免把地面反光误当特效。
- **几何结构**：符线、弧线、颗粒等明确结构，优先在最终画布网格直接制作，核心/细小辉光/颗粒分层。原生绘制不属于照片重采样；原图不缩放。
- **复杂纹理**：若宿主提供可用 image_gen，可用粗图作为参考，仅生成所需透明局部素材。宿主生成尺寸不一定能满足需求；先核实原生像素尺寸，不能默默放大补足。工具失败或素材尺寸不足则停止该路线，使用已可用素材或说明限制。本技能没有 AI/Photoshop API 集成。

正式局部素材用 [assemble_asset.py](generation.md) 按原生尺寸、整数位置放到全尺寸透明图层上，不改变素材尺度；越界或可见像素碰到保护区直接拒绝。基础处理脚本要求最终图层与原图同尺寸。没有专用粗图解析或自动路径提取接口。

## 授权和版本
粗预览确认授予的是明确描述的设计范围，不是无限重绘权。正式方案绑定实际素材、参数、父版本后，在同一明确授权范围内登记已有用户批准；不能伪造新同意。材质制作和修正可直接完成。人物范围、背景、效果布局、强度或风险类型发生实质变化时重新询问；不因为保存文件名变化重复审批。

原方案内的小幅制作修正不需要用户多次确认；内部保留每个实际方案版本及哈希，不覆盖历史。将内部制作草稿与成片版本区分，只展示推荐版本，不连续展示所有失败过程。失败版本不能导出。

## 缓存和计算
- 原图、参考图、保护蒙版、确认过的符纹或材质按内容哈希保存；同一文件由现有 assets 缓存复用。布局变化时只制作受影响图层，禁止重复生成主体、重复计算抠图或把整个项目当作 AI 输入。
- 根据 source/mask/layer/配方/参数的哈希判断能否复用；人或参数改变后不沿用旧结果。脚本已有内容地址素材缓存，没有持久化 AI 结果缓存接口。
- 合成后端只在有效蒙版包围范围内分块计算，处理仍在原始像素网格。此优化降低浮点工作内存，不删除尺寸、保护像素、素材哈希、审批和导出重算验证。
- 展示用缩略图可以缩小，但原件和正式素材不允许降采样。独立背景的放大例外只在用户明确授权后按 scene-integration.md 记录。最终 PNG 压缩、磁盘读写及完整验收依然需要时间。


跨项目复用及高风险视觉门禁见 [场景融合与项目隔离](scene-integration.md)。用户已经明确要求直接导出时不重复要求最后确认。
